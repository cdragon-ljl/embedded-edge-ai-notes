## 1. 张量：深度学习的"多维数组"

### 1.1 从数组到张量

**定义 1（张量, Tensor）**：张量就是多维数组，是深度学习中最基本的数据结构。标量（一个数）、向量（一维数组）、矩阵（二维数组）都是张量的特例。

嵌入式工程师对数组再熟悉不过了，张量只是把"维度"这个概念系统化：

| 名称 | 维度 | 形状示例 | 嵌入式类比 |
|:---|:---:|:---|:---|
| 标量（Scalar） | 0 维 | `()` | 一个 `float` 变量 |
| 向量（Vector） | 1 维 | `(64,)` | 一段 `float buffer[64]` |
| 矩阵（Matrix） | 2 维 | `(32, 64)` | 一张灰度图像 `uint8 img[32][64]` |
| 3 维张量 | 3 维 | `(3, 32, 64)` | RGB 三通道图像，每通道一张灰度图 |
| 4 维张量 | 4 维 | `(16, 3, 32, 64)` | 16 张 RGB 图像打包成一批（batch） |

**定义 2（形状, Shape）**：张量每个维度的大小，如 `(16, 3, 32, 64)` 表示"16 张、3 通道、高 32、宽 64"。形状决定内存布局：在行优先（C 风格）内存中，最右边的维度变化最快，这与 C 语言的二维数组 `a[i][j]` 中 `j` 连续排列完全一致。

嵌入式直觉：一张 `320×240` 的灰度图像就是 `uint8_t frame[240][320]`，一行 320 字节。深度学习里的张量本质相同，只是维度更多、数值类型通常是 `float32`。**唯一的新概念是"通道"**：把多张同样大小的图叠在一起，就多了一个维度。

### 1.2 广播：不同形状怎么运算

**定义 3（广播, Broadcasting）**：当两个张量形状不完全相同时，允许自动扩展其中一个到另一个的形状再运算。规则是：从右往左逐维比较，维度相等或其中一个为 1 即可广播。

嵌入式类比：给一帧图像整体加一个亮度偏置 `offset`，你不会写两层循环去遍历，而是想象"一个标量自动扩展成与图像同形状的数组再相加"。广播就是编译器/运行时替你做了这个扩展——只不过它不真正复制数据，而是让每个元素按规则索引到标量。

```
shape A: (32, 64)
shape B: (64,)      ← 视为 (1, 64)，沿第 0 维复制 32 份
结果  : (32, 64)
```

## 2. 从感知机到神经网络

### 2.1 神经元：加权求和 + 非线性

**定义 4（神经元, Neuron）**：神经网络的基本计算单元。输入向量与权重向量做点积，加上偏置，再经过一个非线性函数（激活函数）输出。

公式（单个神经元）：

```
y = f( w1*x1 + w2*x2 + ... + wn*xn + b )
```

嵌入式类比：这就像传感器融合——把多个传感器的读数各自乘一个权重再求和，加一个偏置（零偏校准），最后过一个限幅/非线性环节（比如饱和限幅、死区）。权重 `w` 和偏置 `b` 就是模型参数，训练的目的就是调好这些参数。

【图1：单个神经元结构示意图】

```text
   x1 ──w1──┐
   x2 ──w2──┤    ┌──────────┐
   x3 ──w3──┼──▶ │ Σ(wx)+b   │──▶ f(·) ──▶ y
   ...      │    └──────────┘
   xn ──wn──┘        ↑
                 偏置 b
```

> 图1 生图 prompt：极简示意图，白色背景，左侧 4 个输入节点（蓝色小圆）经 4 条带权值的线（线粗细代表权重大小）汇聚到中间一个求和节点（橙色圆，标注 Σ），再经激活函数方块（绿色，标注 f）输出右侧节点（红色）。中文标注"输入 x1~xn / 权重 w / 求和 / 激活函数 / 输出 y"。比例 16:9，扁平插画风。

### 2.2 全连接层：一整层神经元 = 矩阵乘法

一个神经元处理一个输出；把 N 个输出神经元排成一排，就得到**全连接层（Fully Connected Layer）**：

```
y = W · x + b
```

其中 `W` 是 `(N_out, N_in)` 的权重矩阵，`x` 是 `(N_in,)` 的输入向量。这正是你在矩阵乘法优化篇里手写的 GEMM！一个全连接层的前向计算就是一次矩阵乘法加一次逐元素加偏置。

这就是为什么 **GEMM 是深度学习的核心算子**：全连接层是 GEMM，卷积层也可以转化为 GEMM（im2col，后面会讲到），Transformer 的自注意力更是三次 GEMM。你在 CUDA 上优化过的每一个 tiling 技巧，都会在真实模型中反复被调用。

### 2.3 激活函数：非线性来源

如果只有线性变换 `W·x+b`，无论堆多少层，整体仍然是一个线性函数（矩阵乘法满足结合律，多层线性 = 单层线性），模型表达能力会非常有限。激活函数引入非线性，让网络能拟合任意复杂函数。

常用激活函数（嵌入式类比）：

| 激活函数 | 公式 | 嵌入式类比 |
|:---|:---|:---|
| ReLU | `max(0, x)` | 半波整流 / 死区限幅 |
| Sigmoid | `1 / (1 + e^-x)` | 饱和限幅（软限幅），输出 (0,1) |
| Tanh | 双曲正切 | 对称软限幅，输出 (-1,1) |
| GELU | `x · Φ(x)` | ReLU 的平滑版，Transformer 常用 |

ReLU 实现极其简单（一个比较指令），且在正区间导数为常数 1，不会造成梯度消失，因此是 CNN 的事实标准。

## 3. 训练：模型参数从哪里来

### 3.1 损失函数：衡量模型有多错

**定义 5（损失函数, Loss Function）**：衡量模型预测值与真实标签差距的函数，训练的目标就是让损失尽量小。

两个最常用的损失：
- **均方误差（MSE）**：回归任务，`L = (1/N)·Σ(y_pred - y_true)²`，像计算一组测量值与基准值的均方差。
- **交叉熵（Cross Entropy）**：分类任务，`L = -Σ y_true · log(y_pred)`，像信息论里的编码代价——预测概率越离谱，代价越大。

### 3.2 梯度下降：沿着最陡方向下山

**定义 6（梯度下降, Gradient Descent）**：参数更新的迭代算法。每一步计算损失对每个参数的偏导数（梯度），然后朝梯度的反方向迈一步：

```
w ← w - lr · ∂L/∂w
```

其中 `lr` 是学习率（步长）。嵌入式类比：你在山顶（损失大），梯度告诉你"哪个方向下降最快"，学习率就是你的步长——步长太大容易来回震荡，太小收敛太慢，就像 PID 调参数时增益过大导致振荡。

【图2：梯度下降示意】

```text
           损失 L(w)
             ╱╲
            ╱  ╲
           ╱    ╲        ← 参数 w
          ╱  ●   ╲           ● = 当前点
         ╱  ↓     ╲          ↓ = 负梯度方向（下山）
        ╱   ●      ╲
       ╱    ↓       ╲
      ╱_____●________╲
```

> 图2 生图 prompt：2D 折线/曲线图，横轴"参数 w"、纵轴"损失 L(w)"，一条深蓝色抛物线，抛物线上标 3 个红色圆点从高处沿曲线下滑到谷底，每个点带箭头指向下坡方向，标注"学习率 = 步长"。白色背景、扁平信息图风格，比例 16:9，中文标注。

### 3.3 反向传播：梯度怎么高效计算

**定义 7（反向传播, Backpropagation）**：利用微积分链式法则，从输出层向输入层逐层计算每个参数梯度的算法。

直觉：网络前向传播算出了损失，现在要让每一层的参数知道"自己该往哪个方向调"。梯度从最后一层往前传，每层的梯度 = 上一层传来的梯度 × 本层局部导数。这就像把误差信号沿计算图"反向走一遍"。

GPU 视角：**前向和反向各需要一次矩阵乘法**（反向还要算权重梯度，实际是三次 GEMM 左右），所以训练的计算量大约是推理的 2~3 倍。这就是为什么训练需要更大的算力。

### 3.4 训练 vs 推理：两套完全不同的模式

| | 训练（Training） | 推理（Inference） |
|:---|:---|:---|
| 目标 | 更新参数，最小化损失 | 用固定参数做预测 |
| 数据流 | 前向 + 反向 + 参数更新 | 仅前向 |
| 数值精度 | 通常 FP32/FP16 | FP16/INT8 量化（省显存省带宽） |
| 嵌入式类比 | 出厂前的标定/校准过程 | 固化参数后的正常使用 |

嵌入式类比：训练就像给传感器做标定——采集数据、拟合曲线、确定系数；推理就像标定完成后把系数烧进固件，正常运行。**推理是部署关心的重点**，因为它要在资源受限的端侧设备上长期运行，这也是本系列后面算子优化的主战场。

## 4. 常见模型家族

### 4.1 MLP：多层感知机

**定义 8（多层感知机, MLP）**：若干全连接层 + 激活函数堆叠而成的最基础网络。每一层输出 = 激活(矩阵乘 + 偏置)。

```
x ──▶ [FC+ReLU] ──▶ [FC+ReLU] ──▶ [FC] ──▶ y
```

MLP 适合表格类数据（特征向量 → 标签），是理解所有深度模型的基础骨架。计算核心就是一层接一层的 GEMM。

### 4.2 CNN：卷积神经网络

**定义 9（卷积层, Convolutional Layer）**：用一个小卷积核（如 3×3）在输入特征图上滑动，逐位置做加权求和。**这与你做图像处理时的滑动窗口滤波（Sobel 边缘检测、中值滤波、均值滤波）在数学上完全同构**——区别只是卷积核的权重不是手工设计，而是训练出来的。

嵌入式类比：Sobel 算子是固定的 3×3 核做边缘检测；CNN 让网络自己学出"该用什么核"。卷积核参数共享（同一个核滑遍全图），参数数量远少于全连接层，因此 CNN 特别适合图像。

```
输入特征图 (H, W, C_in)            卷积核 (K, K, C_in, C_out)
   ┌─┬─┬─┬─┐                       每个输出通道一组核
   │ │ │ │ │    滑动窗口          输出特征图 (H', W', C_out)
   ├─┼─┼─┼─┤   ──────────▶          ┌─┬─┬─┐
   │ │▓│▓│ │   Σ(核 ⊙ 窗口)+b        │ │ │ │
   ├─┼─┼─┼─┤                        ├─┼─┼─┤
   │ │▓│▓│ │                        │ │ │ │
   └─┴─┴─┴─┘                        └─┴─┴─┘
   C_in 个通道一起卷
```

**定义 10（池化, Pooling）**：下采样操作，取窗口内的最大值（MaxPool）或平均值（AvgPool）。嵌入式类比：ADC 过采样后的抽取/降采样——降低分辨率的同时保留主要信息，还顺带减少计算量。

### 4.3 RNN：循环神经网络

**定义 11（循环神经网络, RNN）**：处理序列数据的网络，每个时刻的隐藏状态既依赖当前输入，也依赖上一时刻的隐藏状态。

```
h_t = f(W_hh · h_{t-1} + W_xh · x_t + b)
```

嵌入式类比：这就像一个**带记忆的状态机**——当前输出不仅看当前输入，还看内部状态，类似 IIR 滤波器中输出依赖历史输出。RNN 曾经是语音、文本的主流，但由于串行依赖难以并行（每个时刻必须等上一时刻），现在长序列任务已被 Transformer 取代。

### 4.4 Transformer：注意力机制

**定义 12（自注意力, Self-Attention）**：序列中每个元素都与其他所有元素做加权交互，权重由"查询-键-值"（QKV）三组矩阵乘动态计算。

```
Attention(Q, K, V) = softmax( (Q · K^T) / √d ) · V
```

嵌入式类比：想象一个带权重的查找表——每个元素先算出"我要找什么"（Q）和"我能提供什么"（K），两者匹配程度决定"我应该关注谁"（注意力权重），最后按权重把"内容"（V）加权求和。自注意力让序列中任意两个位置可以直接交互，且可以大规模并行——这是它取代 RNN 的根本原因。

从算子角度看，Transformer 的计算核心是：
1. 三个投影 GEMM：`Q = X·Wq`, `K = X·Wk`, `V = X·Wv`
2. 缩放点积：`Q·K^T`（又一个 GEMM/Batched GEMM）
3. Softmax（逐行归一化，含 exp）
4. 加权求和：`Attention·V`（又一个 GEMM）

一个 Transformer 层 ≈ 4~6 个 GEMM + 若干归一化/激活。**优化 GEMM 和 Softmax 就是优化 Transformer 的全部秘密**。

### 4.5 YOLO：目标检测家族

**定义 13（目标检测, Object Detection）**：不仅要分类"图里有什么"，还要定位"在哪里"，输出边界框（bounding box）和类别。

YOLO（You Only Look Once）把图像划分成网格，每个网格单元负责预测中心落在此处的物体：

- 每个网格单元输出：若干候选框的坐标 (x, y, w, h) + 置信度 + 类别概率
- 后处理：非极大值抑制（NMS）去掉重叠的重复框

嵌入式类比：YOLO 像"网格化巡检"——把画面分成小区块，每个区块自己报"我这里有东西、在哪个位置、是什么"，最后合并去重。YOLO 家族（v5/v8/v11 等）是端侧视觉部署最常见的模型之一，因为它在速度和精度之间取得了很好的平衡。

## 5. 可运行代码：用 NumPy 手写两层神经网络

在引入 PyTorch 之前，先用 NumPy 手写一个训练循环，把"前向 → 损失 → 反向 → 更新"四个步骤全部展开。这样你会彻底看清神经网络训练的本质，后面用框架时不会被魔法掩盖。

### 5.1 环境准备

```bash
python3 -m venv venv
source venv/bin/activate
pip install numpy
```

### 5.2 完整代码

```python
import numpy as np

# ---------- 1. 数据：XOR 问题 ----------
# 输入 4 个样本，每个 2 维；标签为异或结果
X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], dtype=np.float32)
y = np.array([[0], [1], [1], [0]], dtype=np.float32)

# ---------- 2. 初始化参数（小随机数） ----------
np.random.seed(42)
n_in, n_hidden, n_out = 2, 8, 1
W1 = np.random.randn(n_in, n_hidden) * 0.5   # (2, 8)
b1 = np.zeros((1, n_hidden))                 # (1, 8)
W2 = np.random.randn(n_hidden, n_out) * 0.5  # (8, 1)
b2 = np.zeros((1, n_out))                    # (1, 1)

lr = 0.5

def relu(x):
    return np.maximum(0, x)

def relu_grad(x):
    return (x > 0).astype(np.float32)

# ---------- 3. 训练循环：前向 → 损失 → 反向 → 更新 ----------
for epoch in range(2000):
    # 前向传播
    z1 = X @ W1 + b1        # (4, 8)  全连接层 1
    a1 = relu(z1)           # (4, 8)  激活
    z2 = a1 @ W2 + b2       # (4, 1)  全连接层 2
    y_pred = 1 / (1 + np.exp(-z2))  # (4, 1)  sigmoid 输出概率

    # 损失：二分类交叉熵
    eps = 1e-8
    loss = -np.mean(y * np.log(y_pred + eps) + (1 - y) * np.log(1 - y_pred + eps))

    # 反向传播（链式法则）
    dy = (y_pred - y) / X.shape[0]   # 输出层误差 (4, 1)
    dW2 = a1.T @ dy                  # (8, 1)
    db2 = np.sum(dy, axis=0, keepdims=True)
    da1 = dy @ W2.T                  # (4, 8)  误差传回隐藏层
    dz1 = da1 * relu_grad(z1)        # 乘 ReLU 局部导数
    dW1 = X.T @ dz1                  # (2, 8)
    db1 = np.sum(dz1, axis=0, keepdims=True)

    # 参数更新（梯度下降）
    W1 -= lr * dW1
    b1 -= lr * db1
    W2 -= lr * dW2
    b2 -= lr * db2

    if epoch % 400 == 0:
        print(f"epoch {epoch:4d}  loss = {loss:.6f}")

# ---------- 4. 验证 ----------
print("\n训练完成，预测结果（>0.5 判为 1）：")
for i in range(4):
    print(f"  XOR({int(X[i,0])}, {int(X[i,1])}) -> {y_pred[i,0]:.4f}  期望 {int(y[i,0])}")
```

运行结果应类似（损失单调下降，预测接近 0/1）：

```
epoch    0  loss = 0.723247
epoch  400  loss = 0.212505
epoch  800  loss = 0.073665
epoch 1200  loss = 0.034995
epoch 1600  loss = 0.020643

训练完成，预测结果（>0.5 判为 1）：
  XOR(0, 0) -> 0.0080  期望 0
  XOR(0, 1) -> 0.9920  期望 1
  XOR(1, 0) -> 0.9918  期望 1
  XOR(1, 1) -> 0.0085  期望 0
```

### 5.3 代码解读（对应前面概念）

- **前向**：`X @ W1` 就是矩阵乘法（GEMM），`relu` 是激活函数，`sigmoid` 输出 (0,1) 概率。
- **损失**：交叉熵，预测越准损失越小。
- **反向**：`dy → dW2 → da1 → dz1 → dW1` 严格按链式法则回传，每一行都能对上公式。
- **更新**：`W -= lr * dW`，就是梯度下降。

注意看：整个训练循环里出现的核心运算只有**矩阵乘法（GEMM）和逐元素运算**。这再次印证：优化 GEMM 就是优化神经网络。

## 7. 小结

本节用嵌入式工程师的语言建立了深度学习的最小知识体系：

- **张量**就是多维数组，广播就是隐式扩展；
- **神经网络** = 一堆"加权求和 + 非线性"的层，全连接层本质是 GEMM；
- **训练** = 前向算损失 + 反向算梯度 + 梯度下降更新参数；**推理** = 只做前向；
- **模型家族**：MLP（GEMM 堆叠）、CNN（滑动窗口滤波 + 降采样）、RNN（带记忆状态机）、Transformer（QKV 加权交互，GEMM 大户）、YOLO（网格化检测）。

这些概念就是后续动手实践的底层支撑：训练一个真实 CNN、导出模型、跑通部署链路时，你会发现每一步都是在跟张量、GEMM、激活函数和梯度打交道——前面学的 CUDA 优化本领也就有了用武之地。
